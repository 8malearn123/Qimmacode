# قمّة كود — صفحة الهبوط

موقع استوديو **قمّة كود** مبني بـ **Next.js 16 (App Router) + React 19 + TypeScript**، منقول من تصميم Claude Design كما هو (نفس المقاسات والألوان والحركات)، وجاهز للنشر على **Vercel** بدون أي إعدادات إضافية.

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:3000
```

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | سيرفر التطوير |
| `npm run build` | بناء نسخة الإنتاج (الصفحة الرئيسية تُولَّد ثابتة) |
| `npm run start` | تشغيل نسخة الإنتاج بعد البناء |
| `npm run lint` | فحص الكود |
| `npm run icons` | إعادة توليد خط الأيقونات بعد إضافة أيقونة جديدة |

## النشر على Vercel

1. من [vercel.com/new](https://vercel.com/new) اختر **Import** لهذا الريبو.
2. Vercel يتعرّف على Next.js تلقائيًا — لا تغيّر أي إعداد، اضغط **Deploy**.
3. أضف متغيرات البيئة الخاصة بنموذج الطلب (القسم التالي) ثم أعد النشر.
4. (اختياري) اربط الدومين من **Settings → Domains**.

## نموذج «طلب مشروع»

النموذج يرسل الطلبات إلى `POST /api/brief`، ويحتاج **قناة توصيل واحدة على الأقل**. أضف المتغيرات في
**Vercel → Project → Settings → Environment Variables** (ونسخة منها في `.env.local` للتجربة محليًا — انظر `.env.example`):

| المتغير | الوصف |
| --- | --- |
| `RESEND_API_KEY` + `BRIEF_TO_EMAIL` | إرسال الطلب بالإيميل عبر [Resend](https://resend.com). يمكن وضع أكثر من إيميل مفصولة بفاصلة. |
| `BRIEF_FROM_EMAIL` | اختياري — المرسِل، مثل `Qimma Code <hello@your-domain.com>` (يلزم توثيق الدومين في Resend). الافتراضي `onboarding@resend.dev` ويصل لإيميل حساب Resend فقط. |
| `BRIEF_WEBHOOK_URL` | إرسال الطلب كـ JSON إلى Webhook: Slack أو Discord أو Zapier أو Make أو n8n… |
| `SITE_URL` | اختياري — رابط الموقع الأساسي لصورة المشاركة (الافتراضي دومين Vercel للإنتاج). |

- بدون أي قناة: في الإنتاج يظهر للزائر خطأ واضح (حتى لا يضيع طلب بصمت)، وفي التطوير المحلي يُطبع الطلب في الطرفية.
- إذا فشل الإرسال يُسجَّل نص الطلب كاملًا في **Vercel → Logs** لاسترجاعه يدويًا.
- فيه حقل مخفي (honeypot) لصد الرسائل الآلية.

### المشاريع ولقطاتها

قسم «من أعمالنا» يقرأ من `lib/projects.ts`، ولكل مشروع لقطات شاشة في `public/projects/`.
مع رابط الموقع الحي (`href`) يفتح الكارد الموقع عند الضغط عليه، ويظهر زر «زيارة الموقع» بجانب الأرقام:

```ts
url: "8ma.sa",                    // العنوان الظاهر في إطار المتصفح
href: "https://www.8ma.sa/",      // رابط الموقع الحي
screens: ["/projects/8ma.webp"],  // مشروع ويب: صورة واحدة 16:9 (لقطة 1440×810 بدقة 2x محفوظة WebP بمقاس 1920×1080)
screens: ["/projects/hood-invite.webp", "/projects/hood-ticket.webp"], // مشروع جوال: صورتان (لقطة 390×760 بدقة 2x محفوظة WebP بمقاس 780×1520)
focus: "right",                   // اختياري: إذا عنوان الصفحة على اليمين، يبقى ظاهرًا لما تقص شاشة الجوال اللقطة
upcoming: true,                   // مشروع لم يعلنه العميل بعد: بلا عنوان ولا رابط، وتظهر «قيد الإطلاق» مكان زر الزيارة
message: { lines, link, time },   // مشروع جوال: رسالة بجانب الجوالين توضح كيف يصل الرابط للناس (تختفي على الجوال)
```

- **بينك كيك** معروض «قيد الإطلاق» بطلب العميل: بعد الإعلان احذف `upcoming` وأضف `url` و`href`.
- **هيت** على رابط Vercel مؤقتًا لأن heetcoffee.com يعرض الموقع القديم: غيّر `url` و`href` بعد نقل الموقع الجديد.
- **هود** بلا رابط لأن كل دعوة شخصية. لقطاته ورسالته لضيف تجريبي (خالد الحربي) في الوضع المحلي للنظام، فلا يظهر فيها اسم مدعو حقيقي ولا تلمس قاعدة بياناته.

### الأيقونات

الأيقونات من **Material Symbols Rounded**، ونحمّل منها فقط الأيقونات المستخدمة (~15KB بدل ~5MB).
لاستخدام أيقونة جديدة: أضف اسمها إلى `ICONS` في `scripts/update-icon-font.mjs` ثم شغّل `npm run icons`
(الأسماء من [fonts.google.com/icons](https://fonts.google.com/icons?icon.style=Rounded)).

## هيكل المشروع

```
app/
  layout.tsx            الخطوط (IBM Plex Sans Arabic + الأيقونات)، الـ metadata، RTL
  page.tsx              ترتيب أقسام الصفحة
  globals.css           ستايلات الصفحة: الحركات، التجاوب مع الشاشات، حالات hover
  api/brief/route.ts    استقبال نموذج الطلب وإرساله
styles/design-system.css  ألوان وخطوط ومسافات نظام تصميم قمّة + الأزرار والحقول
components/             قسم لكل ملف + components/ui للأزرار والأفاتار
lib/                    المحتوى والإعدادات
```
